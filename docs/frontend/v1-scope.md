# JobMatch V1 Scope

## MUST HAVE - V1

- Search
- Filters
- City/location-based search
- Job results
- Job details
- External apply
- Register
- Login
- Logout
- Profile
- Edit Profile
- Match score
- Match explanation
- Matched skills
- Missing skills
- Saved jobs
- Company reviews for logged-in users
- Locked or blurred company reviews for guests
- Simple manual application status
- Loading states
- Error states
- Empty states

## NICE TO HAVE - Later Versions

- CV upload
- AI CV parsing
- Automatic profile creation from CV
- Advanced matching
- Skill-gap recommendations
- Resume tailoring
- Cover letter assistance
- Advanced application tracker
- Notifications
- Interview support
- Career intelligence
- Salary trends
- Ghost-job detection
- Scam detection
